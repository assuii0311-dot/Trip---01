# 2단계 PoC 결과 분류표

T-006 PoC(A~E 단계)의 결과를 요구사항 정의서 12절의 확인 항목 P-01 ~ P-18별로 추출 가능, 불확실, 추출 불가로 분류하고(D-013), 대안 사다리의 단계를 확정한다. 근거는 `docs/02-poc-results.md`(절 번호)와 `docs/02-review-results.md`, `docs/02-data-sources.md`다. 작성일 2026-10-21.

판정 기준

- 추출 가능: 확정한 소스에서 요구사항이 필요로 하는 수준으로 데이터를 뽑을 수 있고 라이선스가 허용한다.
- 불확실: 뽑을 수는 있으나 커버리지나 정확도가 요구 수준에 못 미치거나 타당성이 검증되지 않았다. 대안이나 사용자 확인이 필요하다.
- 추출 불가: 무료 소스로는 뽑을 수 없다. 규칙 기반 추정이나 외부 링크로 대체한다.
