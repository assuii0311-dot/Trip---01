# 4단계 스타일 규칙

- 작성일: 2026-10-25
- 상태: 확정 (2026-10-25, D-026)
- 적용: `docs/04-wireframes.md`의 모든 화면과 이후 구현.

## 1. 원칙

- 현장에서 한 손으로 쓴다. 터치 대상은 44px 이상, 주요 동작은 화면 아래쪽.
- 추정과 사실을 구분해 보인다. 계산값, 추정값, 참고값, 입력 전은 항상 라벨이 붙는다(CLAUDE.md 규칙 1의 화면 판).
- 한국어가 기본이고 현지어·영어는 병기다. 명칭 외의 UI 문구는 모두 한국어.
- 장식보다 정보. 색은 의미에만 쓴다.

## 2. 글자

| 용도 | 크기 | 굵기 |
|---|---|---|
| 화면 제목 | 20px | 600 |
| 카드 제목(한국어 명칭) | 17px | 600 |
| 병기 명칭(현지어 / 영어) | 14px | 400, 보조색 |
| 본문·설명 | 16px, 줄 간격 1.5 | 400 |
| 칩·라벨·근거 문구 | 13px | 500 |

- 글꼴은 시스템 기본(iOS: Apple SD Gothic Neo, Android: Noto Sans KR). 웹폰트는 쓰지 않는다(외부 요청 없음).
- 명칭 병기 형식: `한국어 명칭` 줄 아래 `현지어 / 영어`. 바스크어·카탈루냐어·갈리시아어 지역은 `현지 명칭 · 스페인어 / 영어`(D-021 ⑥). 한국어가 생성 명칭이면 끝에 작은 "생성" 표시.

## 3. 색

| 의미 | 색 | 쓰임 |
|---|---|---|
| 기본 | 검정 #111, 배경 흰색, 보조 회색 #666 | 본문 |
| 강조(동작) | 파랑 #1E63D6 | 버튼, 선택 상태 |
| 확인 필요 | 주황 #D97706 | 영업시간 확인 필요, 토큰 만료 임박 |
| 추정 | 회색 #6B7280 점선 테두리 | 이동 시간 추정, 비용 범위 추정, 검증 안 됨 |
| 대표 명소 | 금색 ★ #CA8A04 | 핀과 칩 |
| 오류·충돌 | 빨강 #DC2626 | 저장 충돌, 입력 오류 |
| 성공·최신 | 초록 #15803D | 버전 최신, 저장 완료 |

- 색만으로 뜻을 전하지 않는다. 항상 아이콘이나 글자를 함께 둔다. 글자 대비는 4.5:1 이상.
- 다크 모드는 후속 범위.

## 4. 간격과 배치

- 8px 격자. 화면 좌우 여백 16px, 카드 안 여백 12px, 카드 간격 8px.
- 세로 화면은 1열. 가로 600px 이상(아이패드 가로, 데스크톱)은 2열: 왼쪽 목록 40%, 오른쪽 지도 또는 상세 60%.
- 하단 탭 56px, 상단 바 48px. 바텀시트는 절반 높이와 전체 높이 두 단계.

## 5. 구성 요소

| 구성 요소 | 규칙 |
|---|---|
| 카드 | 왼쪽 범주 아이콘(24px), 제목·병기, 오른쪽 상태 칩. 탭하면 상세. 길게 누르면 동작 메뉴 |
| 칩 | 13px, 둥근 모서리. 종류: 대표 명소(★ 금), 확인 필요(⚠ 주황), 검증 안 됨(◌ 회색 점선), 예약 필요·권장(🎫), 잠금(🔒), 생성 전(회색) |
| 이동 카드 | 수단 아이콘 + 시간 + 거리 + 신뢰도 라벨("계산", "추정") + 대안 펼침 + 구글맵 링크 |
| 비용 표시 | `€12~18` 범위, 그 아래 근거 문구 13px. 입력 전은 `—` 와 "요금표 입력 전" |
| 지도 핀 | ★ 대표 명소, ● 그 밖, ◌ 검증 안 됨, ✓ 선택됨(파랑), 숫자 핀은 일정 순서 |
| 입력 | 필드 아래 한 줄 오류. 시각은 24시간제, 날짜는 YYYY-MM-DD |
| 버전 표시 | 짧은 SHA 6자 + 시각. 상태 색: 최신 초록, 오래됨 주황, 확인 실패 회색, 충돌 빨강 |

## 6. 표기 규칙

- 시각 24시간제 `09:15`, 기간 `5/1~5/10`, 거리 1km 미만 `850m`, 이상 `1.2km`, 시간 `12분`, `1시간 20분`.
- 금액은 유로 기호 앞 `€15`, 범위 `€12~18`. 소수점 없음.
- 추정값에는 "추정", 데이터 기재 시점이 불명한 값(Wikivoyage 가격 등)에는 "참고"를 붙인다.
- 출처 표기는 장소 상세 하단과 설정 화면에 같은 문구를 쓴다. OSM "© OpenStreetMap contributors", Wikivoyage "CC BY-SA 4.0" 링크, Renfe "CC BY 4.0", 교통 데이터 "Powered by MITRAMS" 링크.

## 7. 접근성과 입력

- 모든 아이콘 버튼에 글자 라벨(aria-label). 음성 듣기 버튼은 설명 상단에 고정.
- 끌어 놓기에는 대체 동작(메뉴의 "다른 날로 이동", "위로/아래로")을 둔다.
- 키보드 포커스 표시를 끄지 않는다(데스크톱).
- 애니메이션은 150ms 이내, 시스템의 "동작 줄이기" 설정을 따른다.
