# E2. 추천 엔진

- 상태: 초안
- 관련 요구사항: R-03, R-05, R-06, R-10, R-18
- 관련 결정: D-012, D-013, D-020, D-021
- 설계 시점: 3단계
- 작성일: 2026-10-25
- 최종 수정일: 2026-10-25

> E1 기준 데이터(설계 동의 D-023)와 2단계 PoC 결과를 바탕으로 작성한 초안이다. "결정 필요" 항목에는 제안값을 적었다.

## 1. 목적

- 사용자의 여행 기본 정보, 여행 형태, 취향과 E1 기준 데이터를 결합해 도시·지역 요약, 선호 분석, 세 수준의 대안을 포함한 후보 추천, 숙박 도시·일수·지역 추천, 예약 필요 여부 제안을 만든다.
- 해외 대표 명소와 그 밖의 장소를 구분해 제시한다(D-020, D-021 ④). 검증되지 않은 장소는 표시만 하고 점수에는 반영하지 않는다(D-024). 점수는 장소의 본질 가치(취향 일치, 대표성, 유산 지정)만으로 매긴다.
- 경계: 날짜별 배치는 E4, 이동 시간은 E3, 한국어 설명은 E5, 비용은 E6. E2는 "무엇을 권할지와 왜"까지만 맡는다. 추천과 무관하게 모든 후보는 열람 가능하다(R-04).

## 2. 입력

| 입력 | 출처 | 필수 |
|---|---|---|
| 여행 도시 목록, 기간, 인원, 공항 | R-01 | 필수 |
| 예산 수준, 하루 시작·마감, 식사 형태 | R-02 | 필수 |
| 취향 선택: 상위 범주 12개 중 선택(결정 필요: 선택·비선택의 2단계 제안. 강도 입력은 두지 않음) | R-03 화면 | 필수 |
| "그 밖의 장소" 비중(결정 필요: 대표 명소 중심 / 균형 / 그 밖 중심의 3단계 제안, 기본 균형) | 화면 | 선택 |
| 장소: 범주, 유산 지정, 사이트링크 수, 언어별 월평균 조회수, 검증 여부, 교차검증 상태, 가격, 영업시간 참고값, 좌표 | E1 places | 필수 |
| 도시: 인구, 층, 가이드 문서 요약, 숙박 밀도(구역별), 가격대 분포 | E1 cities | 필수 |
| 도시 간 이동 시간 | E3 사전 계산 | 선택(일정 수준 대안에 사용) |
| 하루 수용 장소 수 기본값 | E4와 공유(E4 4절) | 필수 |

## 3. 출력

| 출력 | 내용 | 소비자 |
|---|---|---|
| 지역 요약(R-05) | 도시·지역마다 가이드 개요 발췌(영어·스페인어 원문, 한국어는 E5), 1등급 장소 수, 범주 분포, 숙박 밀도, 해외 대표 명소 수 | 화면 |
| 선호 분석(R-05) | 선택 범주와 예산·시간에서 만든 사용자 프로필 문장과 범주 가중치 표 | 화면, E2 내부 |
| 추천 목록(R-06) | 도시별 추천 장소와 점수, 근거 문구, 대표 명소/그 밖 구분, 검증 여부 표시 | 화면, E4 |
| 대안 3수준(R-06) | 전체 일정 기준: 도시 조합과 일수 배분 대안 2개. 도시 기준: 대표 명소 중심 세트와 그 밖 중심 세트. 장소 기준: 추천 장소마다 같은 범주의 근접 대체 2개 | 화면 |
| 숙박 추천(R-10) | 도시별 숙박 일수, 도시 안 추천 구역 3개와 근거(숙박 밀도, 추천 장소 중심과의 거리) | 화면, E4 |
| 예약 필요 여부(R-18) | 장소마다 예약 필요·권장·불필요(추정)와 근거. 사용자가 확정 | 화면 |

## 4. 규칙과 알고리즘

1. 선호 분석: 선택 범주의 가중치 1.0, 비선택 0.3(결정 필요). 예산 수준은 E6 분포의 등급으로, 하루 시간은 E4의 하루 수용 수로 바꿔 함께 프로필 문장을 만든다(예: "박물관과 시장 중심, 중가, 하루 4~5곳").
2. 대표 명소 구분(D-020): 영어 조회 비중(en/(en+es)) 0.5 이상이고 사이트링크 10개 이상이면 "해외 대표 명소", 그 밖은 "그 밖의 장소". 임계값은 결정 필요(제안값은 D 단계 검수 P-17 표본의 갈림 지점에서 잡았다. 추정).
3. 장소 점수(D-024 확정): score = 0.50×취향 일치 + 0.40×대표성 + 0.10×유산 지정.
   - 취향 일치: 장소의 범주 중 사용자 가중치 최대값(선택 1.0, 비선택 0.3).
   - 대표성: 사이트링크 수와 언어별 월평균 조회수를 각각 도시 안 백분위(0~1)로 바꿔 평균한 값. "그 밖의 장소" 비중 설정은 이 항의 부호와 크기를 바꾼다(그 밖 중심이면 백분위를 반전).
   - 유산 지정: Wikidata heritage designation(P1435) 보유 여부. 국가 지정 문화재(Bien de Interés Cultural), 자치주 지정, 유네스코 세계유산 등 177종류를 모두 1로 보는 이진값. PoC 사실: 보유 72,389건, 클래스 수집 장소의 26.5%.
   - 제외한 항: 근접성(숙소·도시 중심에서의 거리)과 검증되지 않음은 장소의 본질 가치가 아니어서 점수에서 뺐다(D-024). 거리는 E4가 일정을 묶을 때 쓰고, 검증 여부는 표시로만 보인다.
4. 추천 목록: 도시마다 점수 순으로 하루 수용 수(E4 기본 3~4곳) × 숙박 일수 × 1.5개를 추천하고, 같은 범주가 연속 3개를 넘지 않게 다양성 제한을 둔다. 근거 문구는 점수 항목 중 상위 두 개를 문장으로 쓴다.
5. 대안 3수준
   - 전체 일정: 입력 도시 목록에 대해 (a) 입력대로, (b) 1등급 장소 수에 비례해 일수 재배분, (c) 도시 간 이동 시간이 4시간을 넘는 쌍이 있으면 중간 도시 삽입 또는 제외를 제안. 각 안에 총 이동 시간과 장소 수를 붙인다.
   - 도시: 대표 명소 중심 세트와 그 밖 중심 세트를 각각 생성해 나란히 보인다.
   - 장소: 추천 장소마다 같은 상위 범주, 2km 안, 점수 차 상위 2개를 대체 후보로 둔다.
6. 숙박 추천(R-10): 도시별 일수 = ceil(추천 장소 수 ÷ 하루 수용 수), 최소 1, 합이 기간을 넘으면 비례 축소. 구역은 선택·추천 장소의 중앙값 좌표에서 1.5km 안 OSM 구역(suburb, quarter, neighbourhood) 중 숙박 수 상위 3개. 구역 데이터가 없는 도시는 도시 중심 반경 1km로 대신한다.
7. 예약 필요 여부(R-18, 클로드 제안 규칙. 사용자 확정): Wikivoyage 목록에 예약 문구가 있으면 "예약 필요(출처)". 유료 입장이고 박물관·미술관 또는 유적·기념물 범주이며 유산 지정 또는 조회수 도시 상위 10%면 "예약 권장". 식당 고가 등급은 "예약 권장". 그 외 "불필요(추정)". 임계값은 결정 필요.
8. 결정성: 같은 입력에 같은 결과. 점수 동률은 내부 ID 순.

## 5. 데이터 의존

E1 기준 데이터만 쓴다. 새 외부 소스는 없다. 조회수 신호는 Wikimedia 페이지뷰(CC0) 3개월 평균, 사이트링크는 Wikidata(CC0). 가이드 요약 원문은 Wikivoyage(CC BY-SA 4.0, 출처 링크 표기).

## 6. 품질 기준과 평가 방법

| 기준 | 목표 | 측정 |
|---|---|---|
| 추천 수용률 | 스페인 계획 수립 때 상위 20개 추천 중 사용자가 선택한 비율 50% 이상 | 선택 기록 |
| 대표 명소 구분 | D 단계 P-17 표본 40곳에서 사용자 판정과 80% 이상 일치 | docs/02-review-results.md 5절 표본 재사용 |
| 예약 규칙 | 표본 20곳에서 사용자 확정과 70% 이상 일치 | 사용자 확정 기록 |
| 숙박 구역 | 추천 구역 3개 중 하나가 실제 예약 지역과 일치 | 사후(11월 예약 뒤) |
| 결정성 | 같은 입력 두 번 실행이 같은 결과 | 자동 테스트 |

## 7. 대안 사다리

| 상황 | 대안 |
|---|---|
| 조회수 없음(소도시 장소) | 사이트링크 수만으로 대표성 계산. 둘 다 없으면 대표성 0, "그 밖의 장소" |
| 구역 데이터 없음 | 도시 중심 반경 1km |
| 가이드 요약 없음 | Wikidata 설명 한 줄, 없으면 수치 요약만 |
| 사용자 취향 미입력 | 모든 범주 가중치 1.0(대표성 순) |

## 8. 관련 결정

- D-012 엔진 분리. D-013 대안 사다리. D-020 P-17 용도. D-021 ④(대표 명소 구분), ⑤(검증되지 않은 장소 표시. 감점은 D-024로 삭제). D-024(점수는 취향 일치·대표성·유산 지정만, 0.50/0.40/0.10).
- 결정 필요: (a) 취향 입력 형태(2단계 선택), (b) "그 밖의 장소" 비중 3단계, (d) 대표 명소 임계값(영어 비중 0.5, 사이트링크 10. PoC 사실: 조회수 보유 문서 19,049건 중 두 조건 모두 369건, 영어 비중만 1,110건), (e) 예약 규칙 임계값(조회수 상위 10%), (f) 비선택 범주 가중치 0.3. (c) 가중치는 D-024로 확정.
