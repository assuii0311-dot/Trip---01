# E6. 비용 추정 엔진

- 상태: 설계 동의 (2026-10-25, D-023)
- 관련 요구사항: R-26 (입력으로 R-01, R-02, E4 결과)
- 관련 결정: D-013, D-021
- 설계 시점: 2단계 PoC와 병행
- 작성일: 2026-10-25
- 최종 수정일: 2026-10-25 (설계 동의 반영)

> 2단계 PoC 비용 확보율(`docs/02-poc-results.md` 26절)과 재조정 ③(D-021)을 바탕으로 작성한 초안이다.

## 1. 목적

- 일정에 대해 숙박비, 입장료, 식비의 범위를 데이터 기반으로 추정하고, 교통비는 요금 데이터가 있는 도시에서만 추정한다(R-26, D-021 ③). 사용자 입력 기반 추정은 하지 않는다.
- 경계: 가격 데이터의 수집과 정규화는 E1, 이동 횟수와 수단은 E3·E4가 준다. E6는 계산과 근거 표시만 맡는다.

## 2. 입력

| 입력 | 출처 | 필수 |
|---|---|---|
| 인원, 기간 | R-01 | 필수 |
| 예산 수준(저가·중가·고가. R-02 가안), 식사 형태 | R-02 | 필수 |
| 일정(날짜별 장소, 식사 수, 숙박 도시와 일수, 이동 구간과 수단) | E4 결과 | 필수 |
| 장소 가격(price_eur, is_free, price_tier, 출처) | E1 places | 필수 |
| 도시 가격대 분포(sleep·eat의 저가·중가·고가 비율과 중앙값·사분위) | E1 cities.price_profile | 필수 |
| 대중교통 요금(1회권 가격) | GTFS fare_attributes(마드리드 CRTM, 메트로 빌바오) | 선택 |
| 택시 요금표 | E1 cities.taxi_fare(개발 시점 데이터 입력. 바르셀로나 확인) | 선택 |

## 3. 출력

- 항목별(숙박비, 입장료, 식비, 교통비) 하루 단위와 전체 합계의 {min, max, basis(근거), confidence(계산·추정·입력 전)}.
- 교통비는 데이터가 있는 도시만 값을 내고, 그 외 도시는 "요금표 입력 전"으로 표시한다. 기차는 Renfe 링크.
- 소비자: 화면(일정표의 비용 영역), E7(여행 데이터의 CostEstimate 저장).

## 4. 규칙과 알고리즘

1. 입장료: 장소에 price_eur가 있으면 그 값(min=max). is_free면 0. 없으면 같은 상위 범주의 도시별 사분위(없으면 전국. PoC: see 중앙값 €5, 사분위 €2.5~8)를 범위로 쓰고 신뢰도 "추정". 유료 가능성이 낮은 범주(광장·거리, 해변, 자연·전망, 공원·정원)는 0으로 둔다(D-023).
2. 식비(D-023 확정): 기본은 하루 2끼(점심, 저녁)이고 아침은 숙박에 포함된 것으로 본다. 식사 형태(R-02 가안)별 조정은 "가볍게"는 2끼를 한 등급 아래 가격으로, "간식 포함"은 저가 등급 반값의 끼니 1회 추가, "반주"는 끼니마다 drink 중앙값(€10)을 추가한다. 예산 수준(저가·중가·고가)은 같은 이름의 등급에 1:1 대응한다. 끼니당 금액은 그 등급의 도시별 중앙값(없으면 전국. PoC: 전체 중앙값 €19, 사분위 €10~30)이고 범위는 사분위다. 인원을 곱한다. 식사 형태 항목이 R-02 확정 때 바뀌면 이 대응표만 고친다.
3. 숙박비: 도시의 sleep 가격 분포에서 예산 수준 등급의 중앙값과 사분위(전국 중앙값 €90, 사분위 €50~135)를 1박 객실 기준으로 보고 일수를 곱한다. 인원 환산은 2인 1실 기준이며 3인 이상은 객실 수를 올림한다(D-023).
4. 교통비: 도시 안 대중교통 이동 횟수(E3·E4) × 1회권 가격(fare_attributes). 마드리드와 빌바오만 계산. 택시는 요금표가 있으면 기본요금 + km × 단가(최소 요금 적용), 없으면 "요금표 입력 전". 기차는 Renfe 링크만. 비행기·배는 다루지 않는다(D-021 ②).
5. 신뢰도: 장소 값 또는 요금 파일이면 "계산", 분포 기반이면 "추정", 데이터 없음이면 "입력 전". 근거 문구에 출처와 기준(예: "마드리드 식당 중가 중앙값 €19, Wikivoyage 23건")을 적는다.
6. 가격 시점: Wikivoyage 가격은 기재 시점이 불명이다. 범위 표시와 "참고값" 문구로 다룬다(추정).

## 6. 품질 기준과 평가 방법

| 기준 | 목표 | 측정 |
|---|---|---|
| 입장료 | 표본 20곳의 실제 입장료(공식 사이트)가 범위 안에 드는 비율 70% 이상 | 사용자 기기 또는 공식 사이트 확인(사용자 행동 일부) |
| 식비·숙박비 | 범위 폭이 중앙값의 ±50% 이내이고 근거가 표시됨 | 계산 검사 |
| 교통비 | 마드리드 1회권 가격이 CRTM 공식 요금과 일치 | 요금 파일 대조 |
| 사후 평가 | 11월 숙소 예약 실제 가격과 숙박비 범위 비교 | 사용자가 기록 |

## 7. 대안 사다리

| 상황 | 대안 |
|---|---|
| 장소 가격 없음 | 범주별 도시 분포 → 전국 분포 → 표시 없음("추정 불가") |
| 도시 가격 분포 없음(Wikivoyage 문서 없는 소도시) | 같은 층(대도시·중소·소도시)의 전국 분포 |
| 교통 요금 없음 | "요금표 입력 전". 개발 시점에 도시 공식 요금표를 데이터로 추가하면 계산으로 전환 |

## 8. 관련 결정

- D-013 대안 사다리. D-021 ③(비용 항목 재결정), ②(비행기·배 요금 미취급).
- D-023(2026-10-25 설계 동의)으로 확정: (a) 식사 형태별 끼니 수와 예산 수준→등급 1:1 대응(4절 2항), (b) 숙박 2인 1실 기준, (c) 무료 가정 범주는 광장·거리, 해변, 자연·전망, 공원·정원, (d) 범위 표시는 "min~max €"와 근거 문구(중앙값은 근거 문구 안에 표기). (a)와 (d)는 초안이 예시만 적었던 것을 클로드가 제안 범위 안에서 구체화한 값이다.
