# 엔진 설계 문서

D-012에 따라 별도 설계와 관리가 필요한 구성 요소를 엔진으로 분리한다. 엔진의 식별과 담당 요구사항은 `docs/01-requirements.md` 6절에 있다.

## 관리 규칙

- 엔진마다 이 폴더에 설계 문서 하나를 둔다. 파일명은 `E<번호>-<영문 이름>.md`이며 `TEMPLATE.md`를 복사해 시작한다.
- 설계 문서 작성은 CLAUDE.md 규칙 3(계획 제시 후 동의)을 따른다.
- 구현은 설계 문서가 "설계 동의" 상태가 된 뒤에만 착수한다.
- 설계 변경은 문서를 먼저 고친 뒤 구현한다.
- 과업은 `docs/TASKS.md`에 엔진별로 설계, PoC, 구현, 검수 단위로 둔다.
- 코드는 엔진별 독립 모듈과 자체 테스트로 분리한다. 구조는 5단계 기술 설계에서 확정한다.
- 상태 값: 미작성(문서 생성 전), 초안, 설계 동의, PoC 중, 구현 중, 검수 중, 완료.
