# E3. 이동 시간 엔진

- 상태: 초안
- 관련 요구사항: R-11, R-12, R-13
- 관련 결정: D-013, D-019, D-021
- 설계 시점: 2단계 PoC와 병행
- 작성일: 2026-10-25
- 최종 수정일: 2026-10-25

> 2단계 PoC E 단계(`docs/02-poc-results.md` 23~25절)와 분류표(`docs/02-poc-classification.md` 2절)를 바탕으로 작성한 초안이다.

## 1. 목적

- 일정표의 연속한 두 장소 사이에 이동 수단별 소요 시간과 거리, 최적안과 대안을 제공한다(R-11). 대중교통은 확정 단계 B + C로 제공한다(R-12, D-021 ⑧). 구간별 구글맵 경로 링크를 만든다(R-13).
- 경계: 어떤 장소를 어느 날에 넣을지는 E4가 정한다. E3는 "두 지점 사이"의 계산과 사전 계산 파일 생성만 맡는다. 비용은 E6.

## 2. 입력

| 입력 | 출처 | 필수 |
|---|---|---|
| 장소·도시 좌표 | E1 기준 데이터 | 필수 |
| 경로 그래프 | OSM 스페인 추출본으로 만든 로컬 경로 엔진 타일(pyvalhalla 3.9.1, 2.1GB). 개발 환경에서만 사용 | 필수(사전 계산) |
| GTFS 노선·정류장 | Renfe 2개, Mobility Database 복사본(주요 도시 18건), 필요 시 NAP·운영사 최신본 | 필수(B 단계) |
| 도시 요금표 | 택시 기본요금·km당·최소 요금(E1 cities.taxi_fare) | 선택 |
| 항공·페리 존재 | OpenFlights 노선 쌍, OSM route=ferry | 선택(섬 구간) |
| 선택 장소 목록과 일정 순서 | E4 또는 화면 | 필수(실행 시) |

## 3. 출력

- Leg(구간): 출발·도착 장소, options[] (수단, 소요 시간, 거리, 신뢰도, 근거, 링크), best(최적안), alternatives(대안 2개까지).
- 수단: 도시 안은 도보, 대중교통(B 추정), 택시(차량), 자전거(선택). 도시 간은 차량, 기차(Renfe GTFS 최단 운행 시간), 비행기·배(섬 구간, 거리 기반 추정과 링크).
- 신뢰도: 계산(로컬 엔진·GTFS 운행 시간), 추정(평균 속도·거리 기반), 링크만.
- 사전 계산 파일: 도시 간 행렬(차량·기차), 도시 안 1등급 장소 행렬(도보·차량), 도시별 대중교통 노선·정류장 요약.
- 소비자: E4(일정 생성), 화면(이동 표시), E6(교통비의 이동 횟수).

## 4. 규칙과 알고리즘

1. 사전 계산(개발 시점, 로컬 엔진)
   - 도시 간: 인구 상위 도시와 공항 도시(결정 필요: 상위 60개 제안)의 차량 행렬. 25×25가 5초였으므로 60×60은 수십 초(추정). 기차는 Renfe GTFS stop_times에서 도시 쌍별 최단 운행 시간과 하루 운행 수.
   - 도시 안: 1등급 장소 쌍의 도보·차량 행렬. 60×60 도보가 2.2초. 도시당 장소 300곳이면 쌍 9만 개(추정 1분 안). 저장 크기는 결정 필요(제안: 도보 2km 이내 쌍만 저장, 그 밖은 실행 시 추정).
   - 섬: 마요르카 등 페리 연결이 그래프에 없는 쌍은 도달 불가로 기록하고 항공·페리 링크로 넘긴다.
2. 실행 시 계산(앱)
   - 사전 계산 값이 있으면 그것을 쓴다.
   - 없으면 직선 거리 × 우회 계수 ÷ 속도. 우회 계수는 PoC 표본 중앙값(도보 1.24, 차량 1.27). 속도는 도보 4.5km/h(FOSSGIS 표본), 도시 안 차량은 결정 필요(제안: 사전 계산 표본에서 도시별 중앙값).
   - 속도 보정(결정 필요): 로컬 엔진 시간은 공개 서버보다 도보 11%, 차량 19% 짧았다. 보수적으로 공개 서버 수준으로 늘리는 보정(도보 ×1.12, 차량 ×1.23)을 제안한다.
3. 대중교통 B 단계
   - 출발·도착 각각 반경(결정 필요: 400m 제안) 안 정류장을 찾고, 공통 노선(직통) 또는 1회 환승 노선을 찾는다.
   - 소요 시간 = 접근 도보 + 대기 기본값(결정 필요: 지하철 5분, 버스 8분 제안) + 정류장 사이 거리 ÷ 수단별 평균 속도(결정 필요: 지하철 30, 트램 18, 버스 14km/h 제안) + 환승 시 추가 대기. 신뢰도는 "추정".
   - 복사본 피드의 유효 기간이 지났으면 노선·정류장만 쓰고 운행 여부는 표시하지 않는다.
4. 택시: 차량 시간에 대기 2분(추정)을 더한다. 요금은 E6.
5. 기차: 도시 간 사전 계산 표에서 최단 운행 시간. 역까지의 접근은 도시 안 도보·대중교통 구간으로 분리해 합산.
6. 비행기·배(D-021 ②): 공항·항구 간 대권 거리로 추정(비행기 거리 ÷ 700km/h + 공항 절차 2시간, 배는 거리 ÷ 35km/h. 둘 다 추정이며 결정 필요). 링크는 구글맵 경로 링크(수단 미지정)와 공항·항구 장소 링크.
7. 최적안과 대안(결정 필요): 기본은 소요 시간 최소. 단, 도보 1.5km 이하면 도보를 최적안으로, 대중교통 추정과 택시는 대안으로 둔다. 대안은 최적안과 다른 수단 중 시간 순 2개.
8. 링크(C 단계, R-13): `https://www.google.com/maps/dir/?api=1&origin=위도,경도&destination=위도,경도&travelmode=transit`. 경유지는 모바일 3개 한도에 맞춰 구간을 나눈다(poc/gmaps_links.py).
