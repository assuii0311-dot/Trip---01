## 3. 불가 판정의 근거

- YouTube Data API: 개발자 정책의 데이터 집계 조항은 "API 데이터를 집계하지 말 것. 예외는 같은 콘텐츠 소유자의 채널에 한하며 그 소유자만 볼 수 있다"이다. 도시나 장소 단위로 영상 수와 조회수를 합산하는 대리 지표는 집계에 해당한다. 할당량과 무관하게 불가다. 영상을 집계 없이 목록으로 보여주는 용도는 가능하지만 요구사항에 없다. 따라서 API 키 발급은 필요 없다.
- Google 검색 결과: 공식 API가 유료(D-001 제외)이고 페이지 자동 수집은 약관 위반이며 결과 내용은 제3자 저작물이다. Trends는 공식 API가 없다.
- Overpass API: 본 서버는 이 환경에서 연결이 끊기고, 두 미러는 서버 오류, 한 미러는 연결 실패다. 추출본 파일 처리로 대체한다.
- datos.gob.es, 마드리드: 봇 차단 서비스가 UA와 무관하게 막는다. 데이터셋의 원 배포처 직접 링크는 E 단계에서 개별 확인한다.

## 4. 수집 설계

### 원칙

- 수집은 스페인 전체를 대상으로 하며 파일 다운로드와 분할 조회로 한다. 커버리지는 표본이 아니라 전체에서 잰다.
- 경로 계산 공개 서버(OSRM, FOSSGIS, Transitous)는 표본 요청으로만 쓴다. 합계 500건 이하, 초당 1회 이하. 전체 규모 계산은 E3 설계에서 로컬 엔진 또는 사전 계산으로 정한다.
- 모든 외부 호출은 식별 가능한 User-Agent(`Trip01-PoC/0.1 (저장소 주소)`)를 쓰고, 동시 요청 1개, 429 응답 시 Retry-After만큼 대기한다.
- 원시 데이터는 저장소에 커밋하지 않고 이 환경의 작업 디렉터리에만 둔다. 커밋하는 것은 스크립트, 요약 수치, 검수 표본이다(D-016).
- PoC 스크립트는 Python이며 가상환경에 패키지를 설치하고 `python -I`로 격리 실행한다. 다운로드한 파일은 전용 디렉터리에 두고 스크립트와 분리한다.

### 교차검증 키 (C 단계)

- Wikidata ID: OSM의 wikidata 태그, Wikivoyage 목록의 wikidata 필드.
- 좌표 근접과 명칭 유사도: ID가 없는 항목의 보조 매칭. 기준은 C 단계에서 분포를 보고 정한다.
- 결과는 후보마다 일치, 불일치, 단일 출처로 기록한다(R-04).

### 품질 검수 표본 (D 단계)

- 층은 셋이다. 대도시, 중소 관광 도시, 데이터 빈약 소도시. 기준은 Wikidata 인구와 OSM 장소 밀도이며 기준값은 B 단계 분포를 보고 제시한다.
- 장소 표본은 층마다 12곳씩 36곳, 지역 요약 검수용 도시는 층마다 2곳씩 6곳. 무작위 추출이며 사용자 선호는 반영하지 않는다(D-016).

### 이동, 비용, 링크 (E 단계)

- 도보와 차량: OSRM 데모와 FOSSGIS로 표본 요청, 그리고 pyvalhalla로 스페인 추출본에서 로컬 타일 구축 가능 여부(디스크, 시간) 검증.
- 대중교통: Transitous는 사용 조건(오픈소스, 비상업) 결정과 사전 연락 뒤에만 경로 호출. 그 전에는 GTFS 원천 데이터(Renfe, NAP, Transitous 제공 목록)를 받아 B 단계(노선과 정류장 기반) 가능성을 본다.
- 수단별: 기차는 Renfe 정적 GTFS 존재 여부, 버스와 지하철은 NAP와 도시 교통공사 GTFS, 택시 요금은 도시 공식 요금표, 비행기는 무료 시간표 부재 확인, 배는 OSM 항로.
- 비용: Wikivoyage 가격 필드와 가격대 분류, GTFS 요금 파일, Renfe 요금.
- 링크: 구글맵 경유지 링크와 My Maps 가져오기는 생성한 링크와 파일을 사용자가 기기에서 연다.

## 6. A 단계에서 확인된 사실 (2026-10-19)

- 환경: 디스크 여유 31GB, 메모리 15GB, CPU 4개, Python 3.13. requests, pandas, lxml 있음. OSM 도구 없음. PyPI에 osmium, pyvalhalla, duckdb, pyarrow의 Python 3.13 리눅스 휠이 있고 가상환경 설치가 된다.
- Wikimedia 속도 제한(2026년 적용): IP만 식별되는 요청 분당 10회, 식별 UA 봇 분당 200회, 인증 사용자 분당 200~2,000회. 동시 요청 3개 이하, Retry-After 준수. 이 환경에서는 같은 IP에서 UA 문자열에 따라 429가 다르게 나왔다.
- 구글맵 경로 링크의 경유지 제한: 모바일 브라우저 3개, 그 외 9개. My Maps 가져오기: KML/KMZ 5MB, CSV 2,000행.
- OSRM 데모 서버: 비상업 합리적 사용, 초당 1회 이하, 무보증. FOSSGIS 서버: 초당 1회, 과다 사용 금지.
- Transitous: 오픈소스이고 비상업이며 자원을 적게 쓰는 프로젝트에 한해 무료. 경로 같은 자원 집약 엔드포인트 사용 전 연락 요구. 출처 링크와 OSM 표기 필수. 원천 데이터 전체 다운로드 제공.
- 라이선스: Wikidata CC0, Wikivoyage CC BY-SA 4.0, OSM ODbL, Renfe와 바르셀로나 CC BY 4.0, Overture 장소 CDLA Permissive 2.0, Foursquare 공개 장소 Apache 2.0.
- 덤프 갱신: Wikivoyage 2026-10-01, OSM 스페인 추출본 2026-10-19.
