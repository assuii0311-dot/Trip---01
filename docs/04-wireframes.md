# 4단계 와이어프레임과 화면 설명

- 작성일: 2026-10-25
- 상태: 확정 (2026-10-25, D-026)
- 근거: `docs/03-screen-flow.md`(S1~S8), `docs/03-feature-spec.md`, 엔진 설계 문서(설계 동의)
- 전제: 세로 화면(아이폰) 기준으로 그린다. 아이패드 가로와 데스크톱은 "목록 + 지도/상세" 두 칸으로 펼친다. 글자 와이어프레임이며 치수는 `docs/04-design-rules.md`를 따른다.
- 프로토타입: 기술 스택 확정 뒤 묶음 2(T-025)에서 코드 프로토타입으로 흐름을 검증한다. 이 문서는 그 전 단계의 배치 합의용이다.

## 공통 틀

```
┌──────────────────────────────┐
│ ◀  화면 제목          버전 ⓘ │  상단: 뒤로, 제목, 현재 버전(짧은 SHA·시각) 또는 저장 상태
│──────────────────────────────│
│                              │
│         화면 본문            │
│                              │
│──────────────────────────────│
│ 입력  탐색  일정  공유  설정 │  하단 탭 5개. 공유자는 입력·탐색이 열람 모드
└──────────────────────────────┘
```

- 상단 버전 표시는 E7 상태(최신·오래됨·충돌·저장 중)를 색과 아이콘으로 보인다.
- 모든 목록 항목은 왼쪽에 범주 아이콘, 오른쪽에 상태 칩(확인 필요, 검증 안 됨, 대표 명소, 예약)을 둔다.

## S1 입력 (흐름 1)

```
┌ 입력 ─────────────────────────┐
│ ① 기본 정보  ② 여행 형태  ③ 취향 │  단계 표시(3단)
│ 기간      [2027-05-01]~[05-10]  │
│ 도시      [마드리드 ×][세비야 ×] │  E1 cities 자동 완성, 칩으로 표시
│           [+ 도시 추가        ] │
│ 공항 입국 [Madrid · Madrid-Barajas Airport (MAD) ×] 21:10 │  검색(도시 영문명·코드·공항명), D-029
│      출국 [+ 공항 검색                     ] 08:30 │  선택 도시 80km 안 공항을 먼저 제안
│ 인원      [2]                   │
│                       [다음 ▶]  │
└────────────────────────────────┘
② 여행 형태: 예산 수준 [저가|중가|고가] 세그먼트, 하루 시작 [09:00] 마감 [22:00],
   식사 형태 [가볍게|보통|반주|간식 포함] 다중 선택
③ 취향: 범주 12개 카드(아이콘, 이름, 예시 장소 3개). 탭하면 선택. 하단 [선택 n개 · 요약 보기 ▶]
```

- 검증: 기간 1~30일, 도시 1개 이상. 오류는 필드 아래 한 줄.
- 서브·공유자는 값만 보이고 편집 불가(흐린 표시).

## S2 요약 (흐름 2)

```
┌ 요약 ─────────────────────────┐
│ 내 선호   "박물관과 시장 중심,  │  E2 프로필 문장
│           중가, 하루 3~4곳"     │
│ 범주 가중치 ▮▮▮▮ 박물관 ▮▮ 시장 │  [다시 선택]
│──────────────────────────────  │
│ 마드리드  ★ 대표 명소 24 · 1등급 310 │  도시 카드
│  "Madrid is the capital…" (영문) │  Understand 발췌. 한국어본은 E5 생성 뒤 표시
│  숙박 밀도 높음 · 가격대 중가 多 │
│  [후보 보기 ▶]                  │
│ 세비야 …                        │
└────────────────────────────────┘
```

## S3 탐색·추천 (흐름 3)

```
┌ 탐색 ── 마드리드 ▾ ───────────┐
│ [추천] [전체 후보]   필터 ⚲ 🔍 │
│ ┌──────── 지도 ────────────┐   │  핀: ★ 대표 명소, ● 그 밖, ◌ 검증 안 됨, ✓ 선택됨
│ │    ★   ●                 │   │  지도는 접기 가능(목록 전체 화면)
│ │  ●   ✓     ◌             │   │
│ └──────────────────────────┘   │
│ 대안 ▸ 전체 일정(2) · 도시(2)   │  대안 패널 열기
│ ─────────────────────────────  │
│ ★ 프라도 미술관 · Museo del Prado│  추천 카드: 점수 근거 2개, 범주, 예약 칩
│   박물관 · 유산 · "취향 일치, 대표성" │  [+선택] [대안 2]
│ ● 산 미겔 시장 · Mercado de San Miguel │
│ ◌ 동네 성당 …  검증 안 됨        │
└────────────────────────────────┘
```

- "전체 후보" 탭은 계층 탐색(지역 → 구역 → 장소)과 범주 필터. 2등급은 도시 선택 시 읽어 들인다(로딩 표시).
- 대안 패널은 바텀시트. 전체 일정 대안은 도시 조합과 일수, 총 이동 시간을 비교표로.
- 카드 탭 → S6 상세(바텀시트 전체 높이).

## S4 선택·배치 (흐름 4)

```
┌ 선택·배치 ────────────────────┐
│ 숙박  마드리드 4박 [Sol·Centro ▾] 세비야 3박 [Santa Cruz ▾] │  E2 추천 구역 3개 중 선택, 수정 가능
│ ─────────────────────────────  │
│ 미배치 (6)   │ 5/1 │ 5/2 │ 5/3 │  왼쪽 선택 목록, 오른쪽 날짜 열. 끌어 놓기
│ 프라도 미술관 │ 레티로│     │     │
│ 산 미겔 시장  │      │     │     │
│ [+ 직접 추가] │      │     │     │
│                                │
│          [일정 생성 ▶]          │  미배치가 있어도 생성 가능(E4가 배치)
└────────────────────────────────┘
```

- 직접 추가: 명칭 입력 + 지도 탭으로 좌표. 교차검증 "사용자 추가" 칩.
- 서브 수립자는 끌어 놓기 대신 "제안" 동작(S7에 기록).

## S5 일정표 (흐름 5, 6)

```
┌ 일정 ── 5/1 5/2 [5/3] 5/4 … ─┐  날짜 탭. 도시 간 이동일은 🚆 표시
│ 09:00 숙소(Sol) 출발            │
│ 🚶 12분 · 0.9km                 │  이동 카드: 수단, 시간, 신뢰도(계산/추정), 대안 ▾, 구글맵 링크
│ 09:15–12:15 ★ 프라도 미술관  🔒 │  항목 카드: 시각, 체류, 잠금, 예약 칩
│    영업시간 확인 필요 ⚠         │  참고값 없음·불일치 표시(D-021 ①)
│ 🚇 추정 18분 · 대안: 🚕 9분 🚶 35분 │  대중교통 B 추정 + 링크
│ 12:40–14:00 🍽 점심 (슬롯)      │  식사 슬롯. 선택 식당이 있으면 채움
│ …                               │
│ 22:00 마감  ▸ 초과분 3곳         │  초과분 서랍(이유 표시)
│ [재생성 ▾] [비용 €] [지도]       │  재생성: 범위 선택(이 날 / 선택 항목 / 전체), 잠금 유지
└────────────────────────────────┘
비용 패널(바텀시트): 항목별 "min~max €"와 근거 문구, 신뢰도. 교통비는 도시별 "입력 전" 표시.
```

- 항목 길게 누르기 → 잠금, 체류 시간 변경, 날짜 이동, 제거.
- 끌어 재배열은 자동 잠금(E4 수정 종류 표).

## S6 장소 상세 (겹침)

```
┌ 프라도 미술관 ─────────────── ✕ ┐
│ Museo del Prado / Prado Museum  │  명칭 병기(한국어 · 현지어 / 영어). 바스크·카탈루냐 지역은 현지 + 스페인어
│ [📍 구글맵(좌표)] [🔎 이름 검색]   │
│ ★ 대표 명소 · 박물관 · 유산 지정  │
│ 예약: 권장(유료·박물관·유산) [확정 ▾] │  E2 규칙 + 사용자 확정
│ 영업시간(참고) 10:00–20:00 ⚠확인 │
│ 입장료 €15 (Wikivoyage, 2024?)   │
│ ── 설명 ──────────── [▶ 듣기]    │
│ 요약(한국어, 2~3문장)            │  미생성이면 영어 원문 첫 두 문장 + "생성 전"
│ 상세 ▾                           │
│ 출처: Wikivoyage(CC BY-SA 4.0), 위키백과 │  attribution_text
│ 교차검증: 일치(3출처) · 검증됨    │
│ 대안 장소: ○○ 미술관, △△ …       │
└────────────────────────────────┘
```

## 상태와 예외

| 상황 | 표시 |
|---|---|
| 데이터 로딩(2등급 도시 파일, 지도) | 목록 자리 표시자와 진행 표시. 1등급은 앱 시작 시 한 번 |
| 최신 확인 실패(API 한도·오프라인) | 상단 버전에 "확인 실패" 회색, 마지막 버전으로 열람 |
| 저장 충돌 | 전체 화면 대화상자: [최신 불러오기(내 변경 보존)] [덮어쓰기(한 번 더 확인)] |
| 토큰 만료 | 저장 시 안내, draft 보존, S8로 이동 버튼 |
| 공유자 | 편집 요소 숨김, 제안 버튼 없음. 상단에 "열람 모드" |
| 서브 수립자 | 편집 요소 대신 "제안" 버튼 |
| 빈 상태 | 각 화면 첫 방문 안내 한 줄과 다음 동작 버튼 |

## 주요 흐름 검증 항목 (프로토타입에서 확인)

1. S1 → S2 → S3에서 추천 카드 선택 → S4에서 날짜 배치 → S5 생성까지 탭 수 20회 이내(추정 목표).
2. S5에서 항목을 끌어 재배열한 뒤 재생성해도 순서가 유지된다(잠금).
3. 공유자가 링크와 Key로 열어 S5가 최신 버전으로 보인다.
4. 세로 화면에서 지도와 목록 전환이 한 번의 탭이다.
