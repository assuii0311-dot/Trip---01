# 3단계 기능 명세

- 작성일: 2026-10-25
- 상태: 초안 (사용자 확인 대기)
- 근거: `docs/01-requirements.md`(2차 확정, D-021), `docs/02-poc-classification.md`, `docs/02-data-model.md`, `docs/engines/` E1~E7
- 관련 결정: D-011, D-013, D-021, D-022, D-023

기능마다 입력, 처리(담당 엔진 또는 화면 규칙), 출력, 저장 위치(`docs/02-data-model.md` 개체), 2단계 판정을 적는다. 화면은 `docs/03-screen-flow.md`, 범위는 `docs/03-mvp-scope.md`에서 다룬다. 표기 규칙은 요구사항 정의서와 같고, 세부 값은 엔진 설계 문서를 따른다.

## 7. 기능 간 의존

```
F-01~F-03 → F-04, F-05 → F-07, F-08 → F-10 → F-11, F-14 → F-17 → F-20, F-21, F-22
F-06(탐색)은 F-01 뒤 언제나. F-09(상세)는 F-06~F-08, F-17 어디서나.
F-12, F-13, F-23, F-24(E7)는 모든 편집 기능의 저장 계층.
F-15(E3), F-16(E2), F-19(E5), F-25는 표시 계층.
```

## 8. 미확정 사항

- R-02 선택지 이름과 수(화면 설계에서 확정).
- 지도 타일 공급자(OSM 타일 사용 정책은 대량·상업 사용 제한. 5단계에서 공급자와 캐시 정책 확정. 결정 필요).
- 엔진 E2, E4, E5, E7의 결정 필요 항목(각 문서 8절).
- 기기 확인(구글맵 링크, My Maps, WebCrypto, 음성 합성)은 사용자 행동.
